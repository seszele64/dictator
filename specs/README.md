# Deprecated location — do not add specs here

This directory (`specs/`) is **deprecated**. The single source of truth for
specifications is [`openspec/specs/`](../openspec/specs/).

- The legacy spec directories that previously lived here
  (`001-persistent-notification/`, `002-streaming-transcription/`) have been
  removed. Their still-relevant requirements live in `openspec/specs/`.
- `002-streaming-transcription` was **never implemented** and is **explicitly
  NOT planned** (decision D2 — see `docs/ROADMAP.md` §10).
- New specifications must go through the OpenSpec workflow
  (`openspec/changes/<change-name>/specs/` deltas, merged into
  `openspec/specs/` on archive) — never into this directory.
